# Elle arrive

Preview locale autonome du hero et de son catalogue caché. Node 22+, aucune dépendance npm.

```sh
npm run dev
npm run check
npm test
npm run build
```

Preview : http://127.0.0.1:4173. Build statique : dist/. Le serveur local ne sert que les fichiers publics autorisés ; ce n’est pas un backend de production. Le site est noindex tant que son lancement n’est pas décidé.

Audit et limites : docs/AUDIT.md. Architecture future : docs/ARCHITECTURE.md. Consignes agents : AGENTS.md. Le déploiement nécessitera HTTPS et reprise des headers de sécurité par l’hébergeur.

Actifs : ribbon.webp, création originale imagegen issue du chat ; Manrope, SIL Open Font License (assets/OFL.txt). Aucun portrait, logo tiers, tracker, cookie ni clé API.
